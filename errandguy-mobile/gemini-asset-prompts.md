# ErrandGuy — Gemini Asset Prompt Library

Every asset below is a **self-complete card**: filename · where it's used · recipe · export spec · a full ready-to-paste prompt. Work through them one by one — each prompt already contains the style, palette, composition, and technical rules, so nothing needs to be assembled.

**Palette (baked into every prompt):** primary `#2563EB` · deep `#1D4ED8` · pale `#EFF6FF` · light tint `#BFDBFE` · warm accent `#F59E0B` · success `#16A34A` · danger `#EF4444` · cool grey `#64748B` · canvas `#F7F8FA`.

---

## Read once — the workflow that makes 69 assets look like one set

1. **Generate the anchor first:** do **#4 `empty-bookings`**, refine until perfect. That fixes your style.
2. **Then chain:** for every other asset, **attach the anchor as a reference image** and add at the top: *"Match the exact style, palette, lighting, perspective and line weight of this reference image."* This is the single biggest quality lever.
3. One subject per image · transparent background · never bake in text/numbers/logos · export **@2x and @3x** (generate large, downscale).
4. Card fields: **Use** = screen · **Recipe** = FLAT / 3D CLAY / MARKER / ICON · **Canvas** = aspect + transparency + target display size.
